## 复核结论

原实现把 App Server JSON-RPC 没有自动任务方法，推断为 Desktop
没有可用的原生入口，因此另建任务存储、计时器及会话发送链路。
本机 Desktop 实际提供 `localAutomations` 主机服务，原结论不成立。
本次通过该服务管理原生任务，移除 Remote 自建调度、JSON 持久化和
组合 `thread/start`、`turn/start` 的执行方式。

| 范围 | 处理 |
| --- | --- |
| 原生桥接 | 使用 MessageChannel 与 Cap'n Web 连接原生服务，只开放列表、历史、创建、更新、删除及立即运行六项方法；接口缺失明确报错 |
| 任务归属 | Desktop 负责存储、调度、权限解析及执行；使用原生项目 ID，保留全部根目录、原生计划、执行环境、通知及自动归档设置 |
| 编辑一致性 | 修改前刷新原生记录并核对更新时间；保留不在当前模型目录中的模型与推理强度，后台旧读取不能覆盖操作结果 |
| 写操作 | 同一任务串行处理，防止双击重复提交；断连、超时或缺少成功确认时保留错误，不自动重发 |
| 历史隐私 | 最多读取最近 200 条运行记录，只投影会话链接及状态，不返回归档消息正文 |
| 加载与界面 | 自动任务按需加载并隔离模块失败；隐藏页面暂停轮询，面板有动效及减少动画适配，窄屏操作区换行 |
| Desktop 窗口 | 调试目标选择主窗口，避免误连头像浮层 |
| 回合时刻 | 使用原生轮次时间，处理无效时间值，窄屏允许换行，保留用时与活动展开行为 |
| 运行包 | 同时生成原生桥脚本，实际加载编译后的 RRULE 模块，保留依赖许可证 |

## 已执行验证

- 全量单元测试：900 项通过、2 项跳过、0 项失败。
- 原生服务缺失、断连、写入超时及超时后迟到服务均有专项覆盖。
- TypeScript 检查、生产构建、运行包依赖及真实 PTY 探针通过。
- 编译后的桥脚本连接本机 Desktop，原生列表及运行历史只读调用成功；
  随后用临时暂停的合成任务完成原生创建、读取、编辑、删除及删除后复查，
  任务始终暂停、没有运行记录，已确认清除。
- 合成浏览器检查覆盖 `scripts/acceptance-viewports.json` 的八组视口：
  列表、长标题、编辑器、回合时间无横向溢出，活动可以展开。
- 合成操作覆盖：保存保留原生 RRULE 及未知模型、原生项目 ID、
  暂停更新时间校验、删除确认、双击只提交一次、未知结果刷新不重发。
  桌面及 320px 窄屏截图已作视觉检查。

## 未完成与使用边界

- 继续现有聊天的 heartbeat 任务可以编辑、暂停和删除；手动立即运行
  仍需在 Desktop 确认当前聊天权限，Remote 不猜测权限参数。
- 原生服务可能拒绝不再受支持的旧任务设置；Remote 不偷偷降级执行环境
  或把多根目录改成首个目录以绕过原生校验。
- 原生暂停任务的创建、读取、编辑、删除已验证；尚未启用、立即运行或
  定时执行自动任务，也未触发模型请求。浏览器的写操作检查使用合成接口，
  原生写入探针不能替代真实定时执行验收。
- iPhone Safari/主屏幕应用与已登录 macOS 的真实自动任务操作仍待验收。
- 管理器自更新与 macOS 签名、公证继续暂停。

原生功能验收时，先在 Desktop 创建一个暂停的无敏感内容任务，再从
Remote 读取并对比名称、计划、项目及环境。依次编辑、暂停/恢复，
在 Desktop 核对同一任务的变化；确认权限与成本后再手动运行一次，
检查只产生一次原生运行记录，并核对会话链接。最后设置一次定时运行，
关闭 Remote 面板，按 Desktop 自身运行条件验证计划执行。
断连时先检查 Desktop 的实际任务状态再重试，不能依据 Remote 报错
直接断定写入没有发生。删除测试任务需再次核对两端。
