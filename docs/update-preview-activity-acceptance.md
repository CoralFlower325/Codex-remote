# 更新、Markdown 与活动分组验收

2026-11-02，Remote 0.2.16 / Manager 0.2.2。本记录描述本批检查范围；
实际安装、发布附件和运行进程以对应部署记录及精确标签的 CI 为准。

## 问题与修复

- 重复子代理状态以前会切断连续命令，但界面只显示第一个子代理入口，造成大量
  分散的执行块。现在只在第一个入口保留边界，后续状态继续参与原生状态投影。
  用户消息、正文、轮次和图片边界继续保留；不改写原生历史。
- 同轮引导前后的回复共享最终答案完成证据。即使时间信息尚未到达，已核实空闲
  且有最终答案的过程也能折叠。运行中或完成状态未知时不强制隐藏。
- 更新进度写盘每次最多尝试三次，间隔 50/100ms；后续写入成功可解除此前错误。
  持续无法保存状态仍阻止服务启停，不用忽略错误换取表面成功。
- 已等于目标版本的文件不再误判为源码定制；准备时仍记录输入摘要，后续修改
  继续阻止停服。真正的配置、包文件和源码定制仍保留冲突保护。
- 下载 GET/HEAD 在显式代理连接明确失败后，允许在原截止时间内直连一次。
  取消、超时和写操作不重试，正文失败继续使用原有来源回退与摘要校验。
- Manager 版本页保留完整摘要，安装时只确认目标版本及简短的离线、数据保留提示。
- Markdown 文件按整篇文档编译，保留跨块列表、表格、代码与引用链接。
  切换文件目标重置源码模式；带行号的定位保留既有源码定位行为。

## 验收边界

合成浏览器检查使用生产构建与隔离数据，未发出真实模型请求、审批或设备通知。
本批诊断也只读取真实会话的类型、数量和布局，不发布聊天内容。
不能把一次正常页面读取等同于已证明用户截图的所有网络、缓存或历史状态。

标准运行包在项目分发可达时无需 Git/npm。真实定制、缺少基线及不支持的平台仍
可能需要源码网络；本批没有证明用户关闭 TUN 后的下载结果。挂起直到超时的代理
不触发额外直连时限。真实 iPhone、已登录 macOS、Gatekeeper、签名及公证仍待验收。
Manager 自更新及 0.2.0AU 继续暂停。
