## PR 处理

保留贡献者的 Desktop 侧聊发现、消息同步、可视视口与紧凑控件、失效线程
退出能力，并在合并前修正：

- 切换主会话清除 side watch、事件 timer 清理后无法再次发布。
- loaded/list 未跟游标、普通临时分支误认侧聊、无原生父 ID 时错绑当前任务。
- 多个侧聊探测互相取消，以及迟到读取或重连重新打开已关闭标签。
- 旧快照覆盖实时文字或完成状态；缓冲 delta 与快照重复合并。
- Desktop 模型/权限设置不同步，迟到快照覆盖请求期间新选择。
- 任意 read/resume 认领 Desktop 临时聊天，或只读客户端夺走既有 owner。
- 服务端旧快照复活已完成轮次，旧完成事件清除新 activeTurnId。
- 恢复五秒心跳、十二秒 pong 截止与两秒 HTTP 候选校验；普通事件和 focus
  不清除 pong 等待，未知模型操作不重放。

Desktop 管理的查看器关闭只移除网页监听；Remote 创建的侧聊关闭仍按原约定
中断并释放。没有启动另一个 Desktop 后端或发送真实模型操作作测试。
