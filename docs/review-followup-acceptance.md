## 实现范围

| 项目 | 文件与行为 | 边界 |
| --- | --- | --- |
| 实时终端目录 | `terminal-cwd.ts` 安装仅对当前 shell 生效的提示符钩子；`terminal-manager.ts` 解析 OSC 7，`terminal-socket.ts` 传递状态，`TerminalPanel.tsx` 展示 | PowerShell、bash 在返回提示符时刷新；zsh 同时监听目录变化。长命令执行中不轮询子进程的目录。未知 shell 或钩子被用户配置覆盖时明确显示不可读取，不冒充实时值 |
| 目录回退 | 未提供任务/项目 cwd 时，连接状态标记回退并显示实际默认路径 | 默认取主机 `CODEX_WORKDIR`，未配置则取主目录。显式路径无效时显示错误，不偷偷改用主目录 |
| 多根目录 | `project-roots.ts` 校验并按项目记住根目录，`ProjectRootPicker.tsx` 提供选择，`Workspace.tsx`/`useRemote.ts` 通过原生 `thread/settings/update` 更新 cwd | 保留现有任务的原 cwd，只有主动选择才修改；运行中、归档或尚未就绪的任务不能切换。浏览器存储不可用时本次选择仍可用，但不能保证刷新记忆 |
| 审查记录预览 | `shared/file-preview.ts` 规范化 `/F:/...`，客户端和服务端各预览入口复用；保留文件 URI、UNC、POSIX 与行号语义 | 不猜测或重写任意损坏路径，不改变 HTML 资源授权与鉴权边界 |
| 权限与模型 | `permissions.ts`、`Composer.tsx` 提供悬停及菜单内可见说明 | 完全访问对应 `danger-full-access` 与 `approvalPolicy: never`；没有新增首次使用弹窗，不改变权限策略 |
| 路径和图片尾项 | `PathText.tsx` 按实际宽度中间截断、悬停全文、复制；接入文件列表、差异标题和预览 | 图片基础 96px 和移动端 84px 是不同作用域，旧冗余声明在 0.2.18 已清理 |

终端仍按**起始目录**保存和恢复标签。shell 中 `cd` 更新当前目录显示，
不会把该标签迁入另一任务的终端组。普通任务切换会恢复对应目录的标签；
主动选择项目根目录时，若原活动标签已 `cd` 到别处、已退出或无法确认目录，
会新建一个从所选根目录启动的标签，保留旧标签及其进程。连接重试不重复新建。
用户配置文件不会被修改；zsh/bash 集成文件只写入 Remote 自己的临时目录。
Windows 实际 PTY 验证与 macOS 现场验收分别记账。

## macOS 操作清单

1. 正常启动现有 Desktop 和 Remote，保留原有 shell 配置；不要改管理器自更新、
   证书、签名或 Cloudflare 托管方式。浏览器打开测试入口并确认版本。
2. 在根 A 打开终端，等“当前目录”出现。执行 `pwd`，与面板完整路径比较。
   如项目是符号链接，允许显示解析后的真实路径，但两者应指向同一目录。
3. 执行 `cd '目录 B 的绝对路径'`，再执行 `pwd`。面板应更新为 B，空格、
   中文及 `#` 原样保留。执行 `cd '不存在的子目录'`，目录应保持 B。
4. 执行 `printf '\033[31mcolour\033[0m\n'`，检查颜色；执行 `sleep 30`，
   按 Ctrl+C，再输入 `pwd`。提示符、按键、命令输出和中断应保持正常。
   如果使用自定义提示符、版本管理器或自定义 `ZDOTDIR`，确认其行为与原来一致；
   如使用 bash，额外核对原登录初始化与退出脚本是否仍按预期工作。
5. 新建第二个终端标签，确认它从所属根目录开始；切回第一个仍为 B。隐藏、
   刷新页面后重新连接，目录与标签内容保留。主动切换项目根目录时若原活动
   标签已在别处，应新增根目录标签，旧标签不被重置或终止。
6. 有已知项目目录但路径不存在时，确认明确报错；对无项目新聊天测试默认目录
   提示。若 shell 不支持目录上报，确认有不可读取说明；这不能算支持实时 cwd 通过。
7. 在项目根选择器切换 A/B，观察任务标题路径及终端归属；新建一个测试任务，
   只要求运行 `pwd` 并返回结果，确认模型实际 cwd 与选择一致。执行中的任务
   不应允许切根；切换失败时原任务路径和已记住的选择保持不变。
8. 在 Safari 和常用桌面浏览器分别打开 Markdown、复制长路径；桌面悬停显示
   全路径。拖宽/缩窄检查器后省略位置随宽度更新，复制仍为全文。
9. 保持 Desktop 登录，手机和 Mac 同时查看同一任务，检查 cwd 设置和聊天状态
   是否同步；同目录终端共享、不同起始目录标签隔离。退出测试时仅关闭自己创建的
   测试终端，不停止 Desktop 或外部隧道。
