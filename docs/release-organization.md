# 版本发布整理

2026-11-01 已统一 24 条历史发布的标题和说明：21 个正式版本及 3 个暂停的
0.2.0AU 草稿。108 个原附件按身份、大小和摘要核对保留，草稿及预发布状态不变，
没有删除历史版本或移动 Git 标签。该轮整理时发布的正式版为 Remote 0.2.12；
当前版本以[最新稳定版](https://github.com/CoralFlower325/Codex-remote/releases/latest)为准。

## 阅读方式

正式版标题采用 `Remote 版本号：本版主题`，说明按“版本”“本版变更”“下载”
“验证与边界”排列。历史页首提供最新正式版入口，历史变更、源码、附件和验证
仍描述该次发布，不改写为当前功能或当前验收。

Remote 与管理器独立计版。当前正式 Remote 为 0.2.38；稳定管理器 0.2.9 安装包位于
[v0.2.31](https://github.com/CoralFlower325/Codex-remote/releases/tag/v0.2.31)。
Remote 0.2.12 当时沿用 v0.2.10 的管理器 0.2.1，没有重打包；历史附件继续保留。

历史 v0.2.1 的同号管理器属于旧同步计版阶段。v0.2.2 将管理器设为 0.2.0
独立基线；随后 v0.2.10 的稳定管理器 0.2.1 是另一构建。两者不能仅按文件名
或版本号混用。

`manager-v0.2.1` 至 `manager-v0.2.3` 保持私有草稿和预发布状态，标题统一标明
“0.2.0AU：暂停存档”及内部版本。其附件不作为日常安装建议；开发线和恢复条件
见 [自更新断点](manager-self-update-checkpoints.md)。草稿正文仅列附件名称，
避免依赖 GitHub 编辑草稿时可能变化的临时下载地址。

## 后续维护

- 每次功能批次保留精确源码标签，正式附件校验完成后再设为最新正式版。
- 每版列出两个组件的版本与分别变更；未改动组件明确注明无变更，并链接原安装包。
- 不为文档整理或历史说明修订增加版本，不重新上传同名安装包或移动已发布标签。
- 修改发布说明前备份完整元数据，修改后核对发布身份、标签、状态、附件与 latest。
  更新 AU 草稿时显式传回原 `tag_name`，并核对原始 Git ref；草稿临时 URL
  不能作为附件身份，身份以附件 ID、名称、大小和摘要为准。
- 最新版附件完成后刷新经校验的公开下载快照并部署分发 Worker；见
  [分发维护](update-downloads.md#维护分发服务)。
