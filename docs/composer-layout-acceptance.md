# 输入草稿与布局验收

Remote 0.2.5，管理器 0.2.0 无变更。

## 行为与边界

主会话输入框卸载后仍保留所属会话的文字、图片、技能和发送中状态。
读图晚于切换完成时写回原会话；发送成功只移除已提交内容，失败保留。
文字沿用 `sessionStorage`；图片和技能仅保存在当前工作区内存，
刷新、更新页面或退出登录后清除，不进入公开缓存或设备聊天快照。
临时侧聊维持内存草稿，关闭标签页后清除。

输入框上方使用固定 80px 缩略图，点击复用现有图片查看器；
移除按钮独立于预览按钮，触屏保持 44px 目标。附件较多时横向滚动，
避免将聊天区挤出屏幕。

对照 Desktop 的会话滚动区与输入区结构，保留短会话从上方开始、
长会话在末尾跟随的行为。历史前插仍使用可见条目锚点；
为短页面暂存的阅读空白在向下阅读结束或回到最新时释放。
末条回复不再叠加轮次间距，输入框增高时更新已贴底的滚动位置。
本次不改写原生记录、顺序、时间或游标。

顶端传输错误改为黑白 `Reconnecting` / `Retry`，真实模型错误仍归属轮次。
运行错误取消自定义彩色卡片与额外标题，参照 Desktop 的紧凑图标文字行，
保留原生进度、JSON 错误消息投影及可展开附加说明。
具体边界见[运行时错误](native-runtime-errors.md)。

## 重现检查

```bash
npm run typecheck
npm test
npm run build
npm run manager:install
node scripts/check-composer-layout.mjs
```

最后两项提供浏览器验收所需的 Playwright；不构建或安装管理器产品。
脚本使用独立本地模拟后端与虚构会话，不连接 Desktop，不向真实模型发送消息。
按 `scripts/acceptance-viewports.json` 的八种视口检查：

- 粘贴时延迟读图，切换到另一会话再返回；选择文件、移除、再切换。
- 点击图片预览、关闭预览，确认图片解码成功与按钮可操作。
- 发送过程中切换会话，成功清除原草稿、保留另一会话草稿。
- 模拟发送失败后切换，保留图片与文字。
- 短页向上加载历史，再向下阅读，释放补偿空白。
- 输入框增高、执行过程展开与折叠后的末条回复间距和贴底状态。
- 页面无横向溢出、无浏览器异常；图片正文未写入浏览器持久存储。
- 重放原生重试进度、429、恢复输出和最终错误，核对文案、转义及灰色紧凑样式。
- 模拟传输中断，顶端仅显示 `Reconnecting` / `Retry`，点击确实建立新连接；
  恢复后隐藏，草稿保留，不重复发送模型请求。

结果与截图写入忽略目录 `output/playwright/composer-025/`。
模拟视口不能替代真实手机键盘、网络或已登录 macOS 的现场验收。
