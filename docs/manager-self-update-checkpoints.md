# 管理器 0.2.0AU 开发断点

2026-10-31 按用户要求暂停管理器自更新与 macOS 签名接入。
正式主线和本机使用 Remote v0.2.2 配套的稳定管理器 **0.2.0**，不含管理器自更新；
后续 Remote 独立修复不改变管理器版本。带自更新的开发线统一命名为 **0.2.0AU**。
AU 是开发线名称，历史包内版本及标签不改写、不复用。

## 保存位置

- 分支 `archive/manager-0.2.0AU`，保存完整开发源码、测试和文档，
  归档点 `2c7aa126a77bdf3c713c68d33b597330e471c960` 已推送 GitHub。
- 原提交 `9496097`、`df69955`、`c60deb7` 分别保留自更新实现、
  Electron 物理程序备份修复和安装器自动重开修复；`2c7aa12` 保留最终 Windows 验收与签名说明。
- 原 `manager-v0.2.1`、`manager-v0.2.2`、`manager-v0.2.3` 标签保持不动。
  对应 Release 作为 **0.2.0AU 开发存档**保留草稿，不进入正式更新渠道，不删除附件或过程。
- 本机程序、设置和更新记录保存在忽略目录 `output/manager-stable-restore/`；
  自更新过程在 `output/manager-self-update-acceptance/`，
  正式包、摘要和双平台打包冒烟在 `output/release-manager-0.2.3/`。
  这些目录可能包含本机私有信息，不提交公开仓库、不作为清理候选。

## 已完成与未完成

开发线已有版本检查、中文摘要、真实下载进度及取消、摘要校验、程序和设置备份、
持久化安装交接与新版启动确认。Windows 官方旧内部版本 0.2.2 → 0.2.3
实机升级已完成独立核对：完成记录、80 项备份、配置保留、自动重开及
Remote/Desktop 原监听进程通过。详细证据和失败过程在归档分支的同名文档中。

macOS 仍只有安装包手动升级；Developer ID 签名、公证及真实 Apple Silicon 升级
验收尚未完成。Windows 包未签名；没有自动程序回滚；跨进程按字节续传不作承诺。
当前不继续实现这些项目，不将 AU 开发代码合入稳定主线。

Windows Store 宿主可能虚拟化 AppData 和安装注册表。验收必须区分宿主虚拟目录
和普通 Explorer 桌面的真实用户数据，不能把同名路径下的不同完成记录混用。
NSIS 引导程序退出也不代表子安装进程已经完成；必须等实际安装文件可读且版本正确。

## 恢复开发条件

1. 用户明确要求恢复 0.2.0AU 开发，先比较归档分支与稳定主线，保留后续 Remote 修复。
2. 准备 Apple Developer Program、Developer ID Application 签名证书及对应私钥，
   将证书导出密码、公证用 App 专用密码或 API key 存入 CI Secrets，不写入源码。
3. 按归档分支的接入说明配置当前 electron-builder 版本的签名、公证与失败阻断；
   保持 appId 和团队身份，用两个真实签名版本完成安装、重开、设置保留及升级验收。
4. 为继续分发的包使用新的有效版本，明确 AU 名称与历史内部版本的对应关系，
   不覆盖旧标签或旧附件。验证完成后另行决定是否恢复正式发布。
