## 发现与修正

只读核对已安装 Desktop 的 heartbeat 解析、显示投影及通知分支。
没有启动第二个 App Server，没有创建或执行自动任务。

| 问题 | 修正 |
| --- | --- |
| 原解析器只接收整条纯 XML，漏掉原生允许的正文加信封、XML 代码块、CDATA | 保留信封外正文；没有额外正文时显示消息；通知优先使用信封内摘要 |
| 未校验决策值，缺少时间戳的普通输入也会被标记成自动任务 | 回复只识别原生 NOTIFY / DONT_NOTIFY；输入要求原生时间戳和指令字段 |
| DONT_NOTIFY 只改变样式，仍发出完成推送 | 完成推送在读取标题与发送之前停止；失败推送仍保留 |
| 流式接收期间仍闪出未完成的信封 | 由当前轮次的原生触发消息识别自动任务，隐藏未完成标签；普通回复片段仍保留 |

所有改动仅作用于显示和通知投影，不改写原始消息、不更改调度或权限。
会话目录、回复复制与消息显示使用同一正文投影。

## 后续验收与边界

部署后，在既有自动任务会话核对普通回复、静默回复、目录与复制；
由真实任务验证 NOTIFY 的通知摘要和 DONT_NOTIFY 不发送完成推送。
失败任务仍应提示失败。iPhone 的 Safari/主屏幕与已登录 macOS 分别验收。

流式标签隐藏需要当前已加载轮次包含可识别的原生触发消息；
缺少该上下文时保留文本，不猜测普通消息的归属。
这里不为原生任务执行、所有通知策略或完整历史覆盖增加承诺。
管理器自更新、签名与公证继续暂停。
