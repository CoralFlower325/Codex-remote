# 代码整理验收

对照基线为 v0.1.16，提交 `6562c1acc4bc40c2123ae3acc6f8929203525122`。
在升级版本号前保留了基线源码、网页构建和 547 项原有测试结果。
本次不增加产品功能，也不改变手机或桌面的交互与视觉设计。

## 整理范围

- 分离历史滚动、轮次回复、执行记录及 Markdown 渲染，解除文件预览对整段时间线的依赖。
- 提取任务和模型、项目目录读取；侧聊与子智能体共用事件投影，保留各自关闭和历史策略。
- 按原顺序拆分样式文件；合并后与基线声明逐字一致。
- 分离服务端装配、聊天 HTTP 路由及 WS/SSE 共用连接处理；统一 45 个 RPC 方法的类型与允许列表。
- 分离管理器窗口层与安装操作层，拆分版本读取、更新准备和安装事务，保留原有中断恢复。
- 浏览器库归入构建依赖；运行包筛除测试缓存、调试符号和其他平台预编译文件。目标终端二进制及 macOS 可执行辅助程序保留，调试符号另存 CI 产物。

## 独立复核

三位独立子代理分别审查客户端、服务端与更新器、管理器与运行包。
复核使用隔离合成数据，没有为验收创建真实模型回合、修改真实密码或撤销真实设备。
