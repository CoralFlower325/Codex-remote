# PDF 附件与工作区修复验收

日期：2026-11-01。源码版本：Remote 0.2.12；稳定管理器 0.2.1 无变更。
本文记录本批合成测试与本地检查的范围；正式发布、平台 CI 和实际部署以对应回执为准。

## PDF 上传与成果预览

输入框支持图片与 PDF。PDF 经认证和可信 Origin 检查后保存到主机私有
`data/document-attachments/`，上传失败可重试，未完成前阻止发送。
主聊、侧聊、补充要求、队列和中断消息编辑保留文件引用；队列往返继续保留
其他文件和 Applications 上下文。历史和草稿中的 PDF 可打开既有检查器预览、
翻页及下载原文件。

原生提交使用 Desktop 的文本文件上下文封装与绝对主机路径，没有新增模型
PDF 输入类型，也不承诺自动 OCR、向量化或所有模型都能读取该文件。
服务端检查 PDF 签名和 EOF，不是完整解析；损坏或加密文件可能在预览时失败。

单文件上限 20 MiB，存储上限 1 GiB / 2048 份，服务端最多同时接收四份。
上传标识及内容摘要保证重试幂等，拒绝目录、元数据及原文件链接。
未发送附件超过 24 小时后在下次上传时清理。发送前保留的文件不自动过期，
不确定的发送结果也保留原件；页面重载会清除未发送的附件选择。

`node --import tsx output/check-document-upload.mjs` 使用独立认证路由和合成
Composer，覆盖 1440px / 402px、503 后原标识重试、切换草稿归属、上传中发送门禁、
原生文本引用、历史入口、两页 PDF 非空画布及字节一致的原文件下载。
未发送真实模型任务。

## 历史、导航与检查器

设备快照先显示时标明正在同步；原生读取失败保留预览并提供重试。
子代理的旧快照通过 fresh 读取校准，独立读取原生计时，晚到元数据不覆盖较新
实时状态。保留原先的有界历史分页、预加载和阅读锚点。
这些修复不构成用户所述特定任务历史丢失的复现或根因证明。

任务选择写入 `thread` / `archived` 查询参数；刷新、浏览器前进后退和通知打开
沿用认证门禁，并保留无关查询与 hash。合成验收覆盖编码等价 URL、快速切换、
慢读取、归档、原生创建及分支；登录前不读取私有任务。

已打开的内置检查器页签切换后保留。修复长路径撑宽、隐藏检查器拦截点击、
手机页签横向滚动和长图缩得过细；长图缩略图标明裁切，原图可纵向滚动。
检查器验证包含 1440×900、402×874、874×402 与 320×568，零页面异常及横向溢出。

## 终端与登录

终端在快照就绪前关闭输入，切换起始目录重建视图，明确同目录会话共享。
真实 PTY / socket 测试覆盖起始目录、会话隔离和快照，不能代替用户现场目录
问题的复现。登录增加可见密码标签、显示切换与中文失败提示，手机控件可操作。

全量检查使用 `npm run typecheck`、`npm test`、`npm run build`。
`node scripts/check-composer-layout.mjs` 覆盖规定八视口，检查草稿、粘贴、
失败保留、运行中停止和历史锚点。额外浏览器记录位于忽略的
`output/playwright/`。真实 iPhone、已登录 macOS、实际模型读取 PDF 和现场弱网
仍需独立验收，不能由浏览器尺寸模拟或平台 CI 代替。
