# 会话首屏与公式验收

日期：2026-11-01。对应 Remote 0.2.15；管理器 0.2.1 无变更。
本记录描述合成数据验收，实际安装以部署记录为准。
本地全量验证：98 个测试文件、800 项测试、类型检查及生产构建通过。

## 首屏问题与修复

此前首次正文读取、原生订阅接入及完成事件刷新可能交错提交，导致先出现旧页、
随后再次替换。新选择并行读取正文与恢复订阅；订阅在首读期间完成时，先合并
接入后的最新页再展示。首屏期间的完成事件等待该读取结束，再合并补读请求。
同一会话正在打开或已完成同步时，重复点击不重新挂载或清空状态。

原生最终答案可能没有完成时间。已确认原生会话空闲时提前折叠已完成过程，
为时间行保留布局；继续等待原生用时，不估算时间。活动或未知状态不会提前完成。
缺少当前轮次的旧时间页不能清除较新运行轮次，设置读取也不能覆盖较新的原生事件。

正文可以先展示；发送仍要求原生正文、时间信息与订阅全部就绪。再次过期或失败
保留重试入口，显式重试及返回最新仍执行新读取。首次进入另一会话仍需真实网络
读取，不承诺零等待。

## 浏览器检查

生产构建的实际 Workspace 配合隔离 HTTP / WebSocket 后端，使用
`scripts/acceptance-viewports.json` 的八视口，包括 402×874 / 874×402、
DPR 3，并施加四倍 CPU 降速：

- 延迟首读、订阅、时间及模型信息，首个旧页不曾显示。
- 原生最终答案完成时间为空、时间信息晚到，答案位置变化为 0px。
- 重复点击当前会话不增加读取、不替换消息节点，保留草稿。
- 快速切换会话，晚到响应不污染当前会话。
- 旧轮次完成事件及旧时间页不清除新轮次的运行状态。
- 无页面异常、页面横向溢出或真实模型操作。

本地证据：`output/playwright/chat-open-0215/results.json` 及同目录八视口截图。
真实 hook 回归另覆盖首屏期间连续完成事件的串行补读、过期时间页、重试门禁及
HTTP / resume 返回时的模型设置保护。

## 公式检查

生产构建八视口均显示 12 个公式与 12 份 MathML，字体完成加载；支持分式、
上下标、希腊字母、独立公式与长公式内部横向滚动。代码和普通价格保留，
不产生可执行的外部链接。普通聊天无公式模块或字体请求，无页面异常、
资源失败或页面横向溢出。

本地证据：`output/playwright/math-0215/results.json` 及同目录截图。
分隔符、代码、链接、引用变换、货币、未完成公式与 PWA 排除规则另有单元回归。
实现边界见[聊天公式](math-rendering.md)。

## 设备与更新边界

以上不是用户现场特定会话、真实 iPhone 网络或已登录 macOS 的验收。
没有发送真实模型请求、审批或设备通知。

标准运行包可通过项目下载分发获取并校验；现有源码定制安装仍可能回退到
Git / npm。保留本机的源码、依赖及脚本定制，不把安全拒绝覆盖的更新冲突
报告为已消除，也不将本机下载成功等同于关闭 TUN 后的设备验收。
