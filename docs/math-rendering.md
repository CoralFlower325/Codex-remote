# 聊天公式

Remote 0.2.15 支持回复和 Markdown 预览中的 LaTeX 公式。
主会话、侧聊和子智能体共用同一渲染器。

| 输入 | 显示 |
| --- | --- |
| `$x^2$`、`\(x^2\)` | 行内公式 |
| 独立行的 `$$`、`\[` 与 `\]` | 独立公式 |
| 代码片段、代码块和显式 Markdown 链接内的公式文字 | 保留代码或链接内容 |

使用 KaTeX 渲染，公式模块、样式和字体按需加载。普通聊天不请求这些资源，
公开服务工作线程也不预取公式模块。公式保留 MathML，长公式在会话宽度内横向
滚动。原始聊天文字不被改写。

关闭受信任命令，限制公式长度、尺寸和宏展开。没有执行外部资源、任意 HTML
或自定义脚本的能力。非法公式、未闭合的流式输入及加载失败保留文字；
这不是完整 TeX 文档编译器，也不运行文档中的宏包或命令。

验证使用虚构聊天，覆盖截图中的分式、方框、下标、希腊字母与单位，以及
价格、代码、引用、错误公式和窄屏长公式。具体检查与设备边界见
[本批验收](chat-open-math-acceptance.md)。
