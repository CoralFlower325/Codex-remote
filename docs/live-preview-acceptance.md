# 文件预览实时更新验收

2026-11-07，Remote 0.2.22 候选批次；管理器 0.2.3 无变更。
本页记录开发与自测，不代表已发布或部署。

## 行为

- 当前可见文件通过私有、已认证的事件连接接收版本变化；主机每 250 毫秒
  核对文件状态，文本读取合并为最多每 400 毫秒一次，Office 为 2 秒。
- 连续写入、原子替换保存和删除后重建均可恢复；读取失败保留上一版并显示错误。
  临时读取错误最多重试三次，事件连接自动重连，手动刷新仍可使用。
- 文本和 Markdown 保留阅读位置、源码及换行模式；只有原本在底部时跟随追加内容。
  原生行号链接只在明确导航时定位，不随文件更新反复跳回该行。
- PDF、Office 保留页码、缩放与滚动位置，页数减少时收敛到新的末页。
  新页先在独立画布完成绘制，再替换可见画面。Office 转换期间保留最新待处理版本，
  不因连续保存反复取消转换。
- HTML 更新重新载入隔离页面并恢复滚动位置；表单、脚本及其他页面状态会重置。
  图片与文档使用带版本的私有 URL，避免同一路径沿用已解码的旧资源。
- 只监听选中文件自身，不递归监听关联资源或外部网站。切换标签、关闭检查器或
  页面进入后台时取消读取和监听，返回后读取最新版本；隐藏文档释放浏览器渲染器。
- 事件只传版本标识，不传正文。鉴权失效关闭既有连接；元数据、正文、转换结果
  及事件均不进入公开缓存。HTML 目录权限、真实路径校验和转换限制保持原约束。

## 真机步骤

1. 在 iPhone Safari 或主屏幕应用打开一份较长 Markdown，滚到中间；在主机连续
   保存正文，确认内容跟随更新且没有白屏、跳回顶部或丢失源码/换行选择。
2. 滚到底部并追加内容，确认跟随；向上阅读后继续追加，确认停留在阅读位置。
3. 切换预览标签或把应用切到后台，修改文件，再返回，确认只更新当前预览。
4. 打开三页 PDF 的第二页并放大，在主机替换文件，确认页码、缩放和位置保持；
   替换为一页文件，确认显示末页。Office 另需主机已安装 LibreOffice。
5. 在 macOS 用编辑器原子保存、重命名替换和删除后重建文件，确认预览恢复；
   更换网络后确认连接提示及自动恢复，不把旧内容误认为最新。

这些浏览器检查不等于真机 iPhone、macOS 登录集成或真实 Office 持续转换验收。
HTML 不构建项目，也不保留应用运行状态；网络、文件系统与转换速度会影响更新延迟。
自更新、签名与公证继续暂停。
