# 手机输入栏单行与单主操作验收

日期：2026-11-09。功能版本：Remote **0.2.25-rc**，管理器 **0.2.4，无变更**。

## 行为和边界

手机主会话与侧聊输入栏保持单行，不把发送操作、上下文、模型或附件按钮放到第二行。
模型控件继续使用 36px，附件与回合索引继续使用 24px，没有为腾出空间进一步缩小。
浏览器听写入口已移除，文字、附件和技能仍按原草稿规则保存与提交。

运行中的会话只显示一个主操作：

- 输入文字、图片、PDF 或技能为空时显示“停止任务”。
- 存在待发内容时切换为唯一的主按钮，不显示浏览器听写，也不再单独并列一个发送按钮。
- 运行中的发送默认立即引导当前轮次；排队模式保留在待发消息操作中。

该行为不改变原生 `turn/steer`、排队或中断参数，不改写原生会话记录。

## 验证

- `npm run typecheck` 通过。
- `npm test` 通过：127 个文件、1026 项测试通过，另有 1 个文件、2 项平台测试跳过。
- `npm run build` 通过。
- 合成浏览器定向检查覆盖 `scripts/acceptance-viewports.json` 的八组视口，包括
  402×874、390×844、320×568 和 874×402 横屏。
- 所有视口均无横向溢出；输入栏控件的垂直中心一致，确认没有换行。
- 402px 手机上，附件、权限、模型、回合索引和主操作宽度分别为
  24px、36px、180px、24px、36px，五个控件在同一条中心线上。
- 320px 手机上，对应布局仍保持单行；模型文字在剩余空间内截断。
- 运行中空输入只有“停止任务”；输入草稿后只有唯一主按钮，听写按钮数量为 0。
