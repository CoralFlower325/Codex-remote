## 环境要求

| 组件 | 要求 |
| --- | --- |
| 主机 | Windows 10/11 或 macOS |
| 运行环境 | Node.js **22.19 及以上**，包含 npm |
| Codex | 已安装并登录的 Codex Desktop / 兼容的内置 CLI |
| 桌面同步 | 回环地址上的 `9229` 调试端口 |
| 公网访问 | 可选安装 `cloudflared`；Windows 助手需要 Cloudflare 管理的域名 |
| Windows 隧道助手 | PowerShell 7，以及已登录的 `cf` CLI |

项目使用桌面端内部接口，Codex Desktop 更新可能影响兼容性。Linux 桌面集成尚未验证。

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/CoralFlower325/Codex-remote.git
cd Codex-remote
```

### 2. 开启桌面同步

先保存工作并完全退出 Codex Desktop，再使用调试参数启动。正常使用过程中，Remote 不需要重启桌面客户端。

普通启动不保证开启 9229。Codex++ 等启动器可能已代为传入调试参数；
Remote 与启动器可以使用同一个 Desktop 调试端点，它与启动器自己的本地服务不同。
如果端点已经就绪，保持当前 Desktop 运行即可。

Windows 商店安装版，可在 PowerShell 中执行：

```powershell
$package = Get-AppxPackage -Name "*Codex*" | Select-Object -First 1
& (Join-Path $package.InstallLocation "app\Codex.exe") --remote-debugging-port=9229 --remote-debugging-address=127.0.0.1
```

其他 Windows 安装方式，请对实际的 `Codex.exe` 使用相同参数；不同安装包的路径可能有所差异。

macOS：

```bash
open -a Codex --args --remote-debugging-port=9229 --remote-debugging-address=127.0.0.1
```

在本机检查：

Windows：

```powershell
Invoke-RestMethod http://127.0.0.1:9229/json/list
```

macOS：

```bash
curl --fail http://127.0.0.1:9229/json/list
```

结果中应包含 URL 带有 `app://-/index.html` 的页面。该端口能控制本地应用，必须保持本机私有访问。

### 3. 安装并启动

**Windows**

```powershell
npm run setup:windows
npm start
```

安装脚本会按锁文件安装依赖、构建应用，并在尚未配置时要求设置访问密码。

**macOS**

```bash
npm run setup:macos
npm start
```

两套安装命令均按锁文件安装依赖、构建应用，并在首次运行时设置访问密码。后台服务需要使用的设置请写入 `.env`。

打开 **http://127.0.0.1:4545** 并登录。首次密码初始化仅接受本机请求。

### 4. 检查连接方式

Windows：

```powershell
Invoke-RestMethod http://127.0.0.1:4545/health
```

macOS：

```bash
curl --fail http://127.0.0.1:4545/health
```

实时桌面同步应显示 `codex: ready`、`transport: desktop`。若为 `standalone`，说明 Remote 正在使用独立 App Server。

## 工作原理

```text
手机 / 电脑浏览器
        |
        | HTTPS + WebSocket / HTTP events
        v
Cloudflare Tunnel（可选）
        |
        v
本地 Node.js 服务（127.0.0.1:4545）
        |
        | 私有 CDP 桥接（127.0.0.1:9229）
        v
Codex Desktop -> 桌面端所属的 App Server
```

桌面端不可用时，Remote 可以回退到独立 App Server。独立模式**不能共享桌面进程的实时事件**，可通过 `/health` 检查当前传输方式。

## Windows 开启与关闭

构建并设置密码后：

| 文件 | 行为 |
| --- | --- |
| `Start Remote.cmd` | 启用并启动计划任务，检查本地就绪状态，然后打开配置的页面 |
| `Stop Remote.cmd` | 停止服务和隧道，并禁用其登录自启任务 |

关闭远控不会关闭 Codex Desktop。关闭后重新登录系统也不会自动开启，直到再次运行 Start。重复开启不会重复创建运行实例。

若计划任务不存在，首次开启会安装当前用户的任务。存在 `data/cloudflared-token` 时会同时管理隧道。
开启时也会将旧控制台任务迁移到无窗口启动器，控制窗口关闭后 Remote 继续运行，
无需常驻终端。后端日志位于 `data/server.out.log`、`data/server.err.log`。
日常后台运行使用管理器或 Start/Stop 开关；`npm start` 是前台命令。

命令行用法：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/remote-control-windows.ps1 -Action Start -NoBrowser
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/remote-control-windows.ps1 -Action Status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/remote-control-windows.ps1 -Action Stop
```

安装或移除计划任务：

```powershell
npm run install-task:windows
npm run uninstall-task:windows
```

## macOS 开启与关闭

执行 `npm run setup:macos` 后，使用 Git 克隆目录中的可执行文件：

| 文件 | 行为 |
| --- | --- |
| `Start Remote.command` | 服务不存在时安装当前用户 LaunchAgent，启用登录自启，检查就绪状态并打开配置页面 |
| `Stop Remote.command` | 停止远控并禁用登录自启，保留 Codex Desktop 运行 |

远控服务不需要管理员权限。助手从当前 `PATH` 及 Apple Silicon、Intel 的标准 Homebrew 路径寻找 Node；Codex 探测包含 `/Applications` 和 `~/Applications`，也可通过 `CODEX_BINARY` 指定。

```bash
npm run start:macos -- --no-browser
npm run status:macos
npm run stop:macos
npm run uninstall-service:macos
```

服务配置位于 `~/Library/LaunchAgents/com.codex.remote.plist`，日志位于 `DATA_DIR`（默认 `data/`）。已有服务若属于其他项目副本，助手会拒绝覆盖。修改 `.env` 后需要先关闭再开启远控。

macOS 开关管理远控网页服务；独立安装的 `cloudflared` 服务或反向代理需单独管理，关闭远控会使其网页端点停止提供服务。Windows 开关还会管理项目配置的隧道任务。

ZIP 下载可能丢失执行权限，可运行 `chmod +x *.command` 恢复，或使用上述 npm 命令。如果 Node 由 shell 版本管理器安装而 Finder 找不到它，请先在初始化过的终端运行一次 Start，以实际 Node 路径安装服务。

## 公网访问

仅在本机使用不需要域名。需要固定公网地址时，可配置 `codex.example.com` 等主机名。

### Windows Cloudflare 助手

安装 `cloudflared`、PowerShell 7 和 Cloudflare `cf` CLI，并完成登录：

```powershell
npm install --global cf
cf auth login
cf auth whoami
npm run tunnel:windows -- -PublicHost codex.example.com
```

助手会创建或复用远程管理隧道、设置入口、在记录不存在时创建 DNS、本地保存隧道令牌、更新 `.env`，并安装登录任务。已有 DNS 若指向其他目标，不会被覆盖。

默认隧道目标为 `http://127.0.0.1:4545`。本地就绪地址为 `http://127.0.0.1:20241/ready`，普通连接日志位于 `data/cloudflared.log`。

### macOS

`scripts/cloudflared-tunnel.sh` 是保留的交互式本地管理方案，会写入 `~/.cloudflared/config.yml` 并安装系统服务，需要 `sudo`。已有 cloudflared 配置时请先检查脚本。本次发布未重新完成该 macOS 路径的实机验收。

也可使用支持 WebSocket 升级的 HTTPS 反向代理，将请求转发到本地服务，并正确设置 `PUBLIC_ORIGIN`、`ALLOWED_ORIGINS`。不要公开桌面调试端口。

## 配置

将 `.env.example` 复制为 `.env` 后按需修改：

Windows：

```powershell
Copy-Item .env.example .env
```

macOS：

```bash
cp .env.example .env
```

| 变量 | 默认值 | 用途 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 本地监听地址 |
| `PORT` | `4545` | 网页服务端口 |
| `PUBLIC_ORIGIN` | 空 | 最终 HTTPS 来源 |
| `ALLOWED_ORIGINS` | 空 | 额外允许的浏览器来源，逗号分隔 |
| `CODEX_BINARY` | 自动发现 | 显式指定内置 Codex CLI 路径 |
| `CODEX_HOME` | `~/.codex` | Codex 状态和配置目录 |
| `CODEX_WORKDIR` | 用户主目录 | 默认工作目录 |
| `CODEX_DESKTOP_DEBUG_PORT` | `9229` | 本地桌面调试端口 |
| `TRUST_PROXY` | `1` | 在预期的本地代理后信任转发头 |
| `SESSION_DAYS` | `30` | 浏览器会话有效天数 |

使用本地隧道或反向代理时，应保持回环监听。Windows 隧道助手默认转发到 `4545`，改端口时需要同时指定其 `-LocalUrl` 参数。

Windows 会依次探测应用包、独立安装目录和 `PATH` 中的 CLI；macOS 会探测支持的应用位置、独立安装目录及 `PATH`。发现失败时可设置 `CODEX_BINARY`。

## 安全与隐私

本项目面向**可信操作人控制自己的电脑**，并非多用户托管平台。登录用户可以访问会话、图片、所选原生权限允许的模型操作，以及宿主用户的交互式终端。手动终端不在模型权限沙箱内。

- 使用强访问密码，公网访问采用 HTTPS。
- 密码以加盐 `scrypt` 哈希保存。会话 Cookie 经过签名，使用 HTTP-only、`SameSite=Strict`，HTTPS 下启用 `Secure`。
- 错误密码尝试受到限流，可在主机运行 `npm run set-password` 重置密码。
- 不要公开 `.env`、`data/`、隧道凭据、会话密钥、日志或浏览器认证导出文件。
- 桌面调试端口和 App Server 连接保留在本机，只公开受保护的网页入口。
- 完全访问可以执行主机操作，运行任务前应确认权限档位。

公开源码未携带本地运行数据或旧开发提交历史，文档截图使用虚构数据。漏洞私密报告方式见 [SECURITY.md](../SECURITY.md)。

## 主要功能

0.2.1 起，手动停止当前轮次后，最新轮次的原始消息会出现“编辑消息”按钮。
保存并重新发送前，Remote 会重新核对原生状态，通过 `thread/revert` 替换此轮及后续记录，
并保留原消息的附件和技能输入。已经执行的文件修改不会撤销。
仅支持最新被停止轮次的原始消息；运行中、已完成的历史轮次和追加引导消息暂不支持。
取消编辑不会修改记录；回执不确定时保留编辑草稿，且不会自动重发，请先核对会话。

- **共享桌面端会话**：通过同一个桌面后端打开和继续会话，接收桌面端发起的实时活动。
- **项目与任务导航**：按项目组织全部供应商的任务，支持分页、搜索、归档浏览、重命名、归档与恢复。
- **长会话展示**：按需加载更早记录，保留阅读位置，采用桌面端风格的活动摘要与已完成回合折叠。
- **回合导航**：桌面使用原生风格的小横线，预览提问与回复并跳转；手机使用可点选列表。
- **侧边聊天与待发消息**：在检查器标签中打开临时聊天。主聊天支持排队、编辑、删除、引导当前回合，以及将消息转入侧聊。
- **子智能体**：原生委派记录显示为紧凑的子智能体行，包含名称、角色和实时状态。点击后在检查器标签中查看其消息、分页历史和折叠执行过程。
- **工作区与回复操作**：新建宿主文件夹并添加为项目，在侧栏归档聊天，复制回复，以及从指定回复分支。
- **原生模型信息**：模型列表和推理强度来自运行时，也能展示其暴露的自定义模型目录。
- **斜杠命令**：在输入框选择原生命令和技能，支持计划模式、上下文压缩、审查与会话分支。
- **会话级权限**：选择原生只读、工作区或完全访问权限，并回复支持的审批请求。
- **图片与代码审阅**：上传或粘贴图片、查看原图，按文件审阅变更，支持统一与并排差异视图。
- **工作区终端**：在当前聊天或项目目录打开交互式 shell，支持多标签、Ctrl+C、保留进程与断线恢复。
- **响应式浅色界面**：桌面可拖动左右分隔线调整三栏宽度，当前浏览器记住宽度，双击分隔线恢复默认；手机使用导航抽屉，保留紧凑输入框和系统字体。
- **连接恢复**：心跳检测、连接超时、网络与前台恢复，以及按会话保存的浏览器草稿。
- **设备通知**：按需开启任务结束、待答问题和审批的加密 Web Push，在设置中测试送达或关闭本设备通知。
- **快速再次进入**：已成功验证的设备可先打开空白工作区，后台检查登录；任务和聊天仍需服务端鉴权。
- **自托管访问**：密码登录、签名 HTTP-only 会话、本机初始化，以及可选的 Cloudflare Tunnel。
- **Windows 与 macOS 双击开关**：Windows 使用 `.cmd`，macOS 使用 `.command` 开启或关闭远控。

## 响应式布局

首页桌面截图为 **1440 × 900**，手机为 **390 × 844 CSS 像素**。[早期工作区示意图](images/desktop.png)为 2560 × 1440。这些是截图尺寸，不是网页固定渲染分辨率。页面跟随浏览器视口及设备像素比渲染，例如 3 倍屏幕上的 390 × 844 CSS 视口对应 1170 × 2532 物理像素。

宽度小于 720 CSS 像素，或宽度小于 980 且宽高比小于 1.18 时，启用手机布局。触屏宽度小于 1024、高度小于 540 时，横屏也保留手机布局；支持动态视口高度和屏幕安全区域。`scripts/acceptance-viewports.json` 包含 2560×1440、1920×1080、1440×900、1024×768、DPR 3 的 402×874（物理像素 1206×2622）与横屏 874×402（2622×1206）、390×844、320×568。浏览器工具栏可能缩小实际可用视口；模拟尺寸验收不等于手机网络实测。

手机版使用紧凑的顶栏和输入区间距。键盘弹出时布局跟随可见视口，移除重复的底部安全区留白，仍保留屏幕物理安全区。电脑版外观不变。键盘尺寸逻辑有单元测试，真实 iOS 键盘仍需单独验收。

手机主会话和侧聊的附件、对话回合按钮保持 36px，电脑端控件尺寸保持原样。双端侧栏顶部的 Codex 改为普通标题，并移除问号帮助入口，底部“设置”按钮继续提供菜单入口。

手机回合列表弹窗使用与输入框一致的圆角，关闭叉号缩小并保留 44px 点击区域。打开时焦点落在弹窗本身，保留键盘导航。手机输入框内的回合按钮与输入框同底色，触摸和恢复焦点时不显示外圈，键盘焦点通过加深图标提示。电脑端入口底色和焦点轮廓保持原样。侧栏运行图标改由独立 HTML 图层旋转，真实 iOS 桌面网页应用的动画表现仍需单独验收。

手机上从屏幕最左侧 28 CSS 像素内右滑可打开对话侧边栏，在已打开的侧边栏或遮罩上左滑可关闭。有效横向滑动至少移动 56 CSS 像素；纵向滚动、输入区、文字选择和弹窗不触发手势。手势逻辑和触摸事件处理已有自动测试；真实 iOS Safari/PWA 手势仍需单独验收，包括浏览器保留的历史导航手势。

通过 **设置 → 刷新版本 → 检查并更新版本**，将服务器未缓存的版本号和构建标识与当前页面比较。已是最新版时保留页面，不再强制刷新；发现新版后先显示更新摘要，点击 **更新至…** 才下载完整公共页面缓存。确认新版接管后刷新，并显示更新完成摘要。失败可重试，不会移除登录状态、主会话文字草稿或通知订阅。真正更新会清除临时侧聊、待发图片和技能选择。手动启用新版时保留其他窗口仍使用的旧公共资源，后续自然激活时清理过期应用缓存。旧版可在**同一个浏览器或已安装的网页应用中打开 `/update.html`**；独立更新页和 `/version.json` 不走旧首页缓存。独立页检查为最新版时提供返回链接，不会自动跳转。更新需要网络；真实 iOS Safari/PWA 更新仍需单独验收。

右上角的 **切换摘要面板固定状态** 打开当前会话摘要，汇集拉取请求、输出内容、临时侧边聊天、原生子智能体和来源。宽桌面可固定 300px 面板，窄桌面与手机使用可关闭的浮层。PR 来自原生会话附件；输出来自已完成答复的文件链接、生成图片及支持的 MCP 结构化资源活动，不存在的本地输出文件会被过滤。来源包括提供的文件与链接、网页搜索和成功使用的 MCP 连接器。资源点击沿用现有预览与下载检查器。“创建输出”和选择来源文件只追加到现有草稿，等待检查和发送；MCP 入口查看已连接服务，不安装新连接器。摘要分页独立于聊天历史，每批自动读取有上限，可继续 **加载更早的摘要**。未提供受支持链接或资源元数据的服务输出可能缺失。

每个验证完成的功能批次同步发布 GitHub Release，记录版本号、源提交和修改摘要。

## 原生提问与历史详情

主会话与临时侧聊会在输入框上方显示原生异步提问，支持选项与多行自定义答案。首个选项默认选中，但只有点击提交才会发送。回答使用 Desktop 的持久消息格式，运行中通过带有 `expectedTurnId` 的原生引导提交，空闲时开启新回合，不进入普通消息队列。从其他客户端提交且已加载的回答会消除对应问题。未回答的问题在回合完成、Goal 进入下一轮后继续保留；整回合通知内附带的消息立即接收。历史跳转仍保留原来的有界阅读窗口。回答框去掉黑色聚焦轮廓，手机回答字号设为 16px，避免输入时自动放大；保留用户主动缩放页面的能力。

手机与电脑的会话选择栏会为已接收的待答问题显示“待回答”，包含未选中会话的实时提问和原生阻塞式询问。摘要只包含数量，通过现有认证连接广播并在重连时同步；现有有界历史读取也会补充摘要，不增加全历史扫描或包含私密内容的公共缓存。内存索引最多保留 1,000 个会话，每个会话各 1,000 个待答／已答 ID。服务重启后，尚未接收、且位于已加载历史以外的旧问题，需等原生事件或有界历史读取发现后才有标识。真实 iOS 与原生答案提交仍需单独验收。

历史分页保留完整对话正文、提问、审阅使用的文件 diff、记录身份和原生游标。折叠的命令与工具正文在展开时读取原生记录，时间线和命令检查器都有加载与重试提示。已加载的详情和错误状态绑定所属会话，实时完整输出会替代旧的读取错误。历史、计时及底栏读取允许完整响应体在 15 秒内完成，避免健康但较慢的公网下载在 6 秒时被中断重试。这能减少不必要的传输和重试，不能消除隧道网络延迟。新的详情接口需要 Desktop 支持 `thread/items/read`。

回归证据、开源调研与验收范围见[历史与提问排查记录](history-questions-investigation.md)。

## 执行记录

连续的命令、编辑、工具调用与搜索合并为一条紧凑摘要，操作类型交替时也不会拆成多行。查看图片和过程文字保留原来的对话位置；普通推理记录与桌面端一样不单独占行，历史数据保持完整。展开摘要后可查看具体命令、输出、文件路径，以及原生记录中提供的文件差异。

处理中的回复显示“已处理”时长。回合结束后，之前的活动与过程文字收进“用时”折叠入口，最终回复保持可见。计时使用原生回合的时间戳与耗时，刷新和加载历史后仍可恢复；缺失时间数据时不会从网页打开时间编造耗时。用户消息与助手回复之间留出更大间隔，正文和操作行内部仍保持紧凑行距。

展开分组后的异常入口可以筛选失败和已拒绝的记录，两者保留独立状态标签。单次工具失败不会将整个回合标为失败。运行提示跟随原生活跃回合，回合结束后，残留的旧条目状态也不会继续显示为运行中。长分组初始显示最近 60 条，每次加载更早的 120 条；详细输出仅在展开时渲染，展开操作保留阅读位置。

对话和操作行字体按 Windows Codex Desktop 实测参数对齐：使用系统字体栈，字号 14px、字重 430，正文行高 22.75px，折叠标题行高 21px。最终字体渲染仍取决于操作系统、浏览器、缩放设置和可用系统字体。

## 回合导航

聊天区左侧的横线跟随原生回合摘要。悬停或键盘聚焦可预览提问与最终回复，点击或按 Enter 跳转。上下方向键及 Home/End 移动焦点，Escape 关闭预览；当前阅读位置会突出显示。较窄的聊天区和触屏设备使用模型选择器右侧的列表按钮与可点选面板（手机布局为 36px，电脑端保留原有尺寸）。

导航独立遍历原生摘要分页，不受首屏最新 40 条记录限制。原生支持可反向使用的游标时，跳转通过一次读取取得目标回合最多 100 条记录；向前、向后滚动时自动续接附近上下文，无需点击显示按钮，跳转窗口内的用户长消息直接展开。内存最多复用五个跳转窗口、有效期 30 秒，原生变更会使缓存失效。历史仍按有限页加载，也可返回最新消息；新活动不会打断旧窗口的阅读。原生摘要可能省略同一回合内的补充用户消息，这些额外横线会在加载对应历史页后补入，因此不会声称未读历史中的每条原始补充消息都已完整建立索引。

选择聊天时，Goal 和待发引导消息通过已鉴权 HTTP 与历史并行读取，不再等待实时连接同步及会话恢复；发送和修改操作仍需连接就绪。Goal 栏支持原生暂停、开始、编辑目标内容及删除，删除需在栏内再次确认，只有用户主动操作才会提交目标变更。

## 侧边聊天与会话操作

在右侧检查器选择 **新标签页（+）> 侧边聊天**。每个标签拥有独立草稿、模型、支持的推理档位、权限和发送/停止控件。首次发送时才创建原生临时聊天，并继承该时刻主聊天的上下文，之后两边的消息独立。隐藏检查器会保留标签；关闭侧聊标签会中断其正在执行的回合，并释放临时聊天。

模型和推理档位来自原生目录，切换用于下一轮新回合；引导正在运行的回合时，继续使用该回合原有模型。切换侧聊设置会保留草稿及已附加技能，不改变主聊天设置。

侧聊标签和草稿只存在于内存，不写入浏览器存储。WebSocket 短暂断开后有 30 秒恢复宽限，Remote 使用内存事件快照补回遗漏的流式输出。刷新或关闭网页、重启 Remote 会丢失临时界面。这些是由 Remote 管理、原生临时会话支持的标签，不接管 Desktop 已打开的侧聊界面。原生临时会话不支持持久历史命令和待发队列，运行中的补充要求直接引导当前回合。

部分 Desktop 传输只在回合结束时提供临时会话的回复记录。Remote 会显示已提交的请求与原生处理时长，再显示完成后的回复；宿主提供逐条消息事件时使用增量显示。

主聊天运行时发送消息会加入原生队列。输入框上方的紧凑消息条提供 **引导**、删除，以及编辑、在侧边聊天中打开、关闭排队菜单。关闭排队后，当前回合剩余时间内直接发送补充要求。队列与 Desktop 共用，执行时由原生队列消费，避免重复提交。转入侧聊会打开可编辑草稿，并从主队列移除该条消息。

点击 **项目** 旁的文件夹加号，或从项目选择菜单进入，即可浏览宿主目录、新建文件夹并添加为工作区。这些是手动宿主文件操作，独立于模型的会话权限。悬停或聚焦侧栏聊天可归档，在归档视图可恢复。已完成回复下方提供复制和 **分支到新聊天** 菜单；分支包含所选回复对应的回合，不包含之后的回合。

### 子智能体会话

主聊天中部署的子智能体显示原生名称、角色和已知状态。同一回复中的部署、等待和活动记录合并为每个子智能体一个入口，执行过程折叠后仍可点击。在右侧检查器的 **子智能体** 标签中，还会分页查询当前聊天的直属子智能体，包括当前历史片段未加载到的记录和已归档子会话。

点击子智能体后，右侧打开其独立会话，复用原生事件通道，先加载最近消息，再按需加载更早历史。运行中的子智能体会重新加入原生订阅；已结束和已归档会话只读取历史。关闭查看标签仅移除该标签及其 Remote 订阅，不会中断、归档或取消原生子智能体订阅。此面板用于阅读，委派指令仍通过父会话工作流发送；临时侧边聊天保留其独立的关闭并中断行为。

## 文件与网页预览

助手回复中的原生 `codex-file-citation` 引用显示为简短的蓝色文件名链接，点击后打开同一检查器。代码示例和用户消息中的引用语法保持原样。

点击回复中的文件或网页链接，在聊天旁边打开检查器标签页。相对文件路径按对应聊天的宿主工作目录解析，手机也能读取主机文件；再次打开同一文件会复用标签。代码和 JSON 提供高亮、行号、自动换行、复制和下载，支持 `:42`、`#L42` 行号定位。Markdown、HTML 可切换预览与源码。图片及 PDF 在同一面板打开；PDF 渲染器按需加载，提供翻页、缩放和复制本页文字。Office 等二进制文件暂时提供下载，不渲染文档内容。

本地 HTML 在隔离的 iframe 中运行，支持同目录内的相对 CSS、图片、脚本和模块。资源链接具有 15 分钟的目录读取权限，不应分享；过期后使用刷新按钮更新。此功能不会替源码项目启动开发服务器或执行构建。外部网站可能禁止嵌入，此时使用工具栏的新标签页按钮。

网址从浏览器所在网络加载；本功能尚未将仅主机可访问的 `localhost` 开发服务代理给远程手机。

仅活动预览加载内容，隐藏后释放文档渲染器。本地 HTML 先获取正文再放入隔离框架，读取失败会明确显示；重新打开时更新资源权限链接。预览元数据及 HTML 读取超过 15 秒会超时，可用刷新按钮重试。预览模块加载失败时保留聊天并显示重新加载入口。PDF 绘图缓冲限制为 800 万像素、单边最多 8192 像素，限制高像素密度设备缩放时的内存占用。文件内容不进入公开静态缓存。读取主机文件属于手动操作，独立于模型权限配置。向上插入历史时，以当前可见消息为锚点，在绘制前及后续布局变化时保持阅读位置。

用户发出的图片以小缩略图排列在文字气泡上方，桌面为 96px、手机为 84px，点击可查看原图。Remote 收到或读取本地附件时，会在主机私有目录 `data/image-attachments/` 保留副本，避免临时文件清理后无法显示。此目录属于私有运行数据，不进入 Git 或公开缓存，副本保留至操作者手动清理。若旧图在保留前原文件就已被删除，Remote 无法恢复，会显示不可用与重试图标。

## 工作区终端

点击顶栏终端按钮，或使用 Ctrl/Cmd+J。Windows 优先使用已安装的 PowerShell 7，否则使用 Windows PowerShell；macOS 使用宿主用户的登录 shell。输入的命令直接在终端执行，不经过模型。

终端按启动工作目录归属。同目录聊天共用终端标签；切换目录会恢复对应标签。shell 内执行 `cd` 不会改变该归属。隐藏按钮只收起面板，标签旁的删除按钮才会结束终端。刷新网页或断线重连保留进程，并恢复最近 1,000 行滚动记录；停止或重启 Remote 会结束这些进程并清空终端。

终端使用独立的已认证 WebSocket，浏览器渲染组件仅在打开时加载。输出不触发聊天记录重绘，服务端只在有界内存中保留屏幕状态。手机提供 Ctrl+C、Tab、Esc、历史方向键与回车控件。

这些是 **Remote 独立管理的 shell**，不接管 Desktop 已打开的终端，也不等于模型的命令记录。它们以宿主用户身份运行，**不受当前聊天的模型权限配置限制**，因此远控登录仅应交给受信任的机器操作者。Remote 不持久保存终端记录；所选 shell 仍可能按自身配置保存普通命令历史。

## 斜杠命令

在输入框开头输入 `/`，即可浏览命令和已启用的原生技能。继续输入可筛选，使用上下方向键与 Enter/Tab 选择，也可直接点击或触屏选择。Escape 关闭菜单并保留草稿；中文输入法确认候选词不会误执行命令。

| 命令 | 操作 |
| --- | --- |
| `/new` | 新建聊天；`/clear` 为别名 |
| `/model` | 打开原生模型选择；`/model <模型标识>` 直接选择列表中的模型 |
| `/reasoning` | 打开当前模型的推理档位，也可带支持的档位参数 |
| `/permissions` | 打开当前聊天的权限；`/approvals` 为别名 |
| `/plan` | 切换原生计划模式；`/plan on`、`/plan off` 明确开启或关闭 |
| `/skills` | 浏览当前工作目录的已启用技能 |
| `/<技能名称>` | 使用原生技能输入，将技能附加到下一条消息 |
| `/compact` | 请求压缩当前已保存聊天的上下文 |
| `/review` | 选择未提交修改、基准分支、指定提交或自定义要求进行审查 |
| `/fork` | 从已保存聊天分叉，并以分页历史打开新聊天 |
| `/rename` | 打开重命名；`/rename <名称>` 直接修改 |
| `/diff` | 打开已加载历史对应的文件变更检查器 |
| `/status` | 查看连接、模型、推理强度、模式、权限、目录与上下文用量 |
| `/mcp` | 读取原生 MCP 服务器状态并遍历返回的分页 |
| `/help` | 返回命令菜单 |

选择技能会添加可移除的附件，随后正常输入要求并发送。向运行中的任务补充要求时也会携带原生技能参数。已停用技能不显示；与内置命令同名的技能仍可从 `/skills` 选择。

`/plan <要求>` 会启用计划模式，并把要求留在输入框内，确认后再发送。模式参数使用当前供应商模型和推理档位，桌面端发起的模式更新也会反映到 Remote。压缩、审查和分叉需要已保存聊天；这些操作及模式切换在任务运行时不可用。设置类命令会保留已添加的图片。

命令调用当前所属的 App Server 或打开对应界面。执行失败会保留命令草稿并显示原生错误；未知斜杠单词不会悄悄作为普通提示词发送。包含后续斜杠的路径和多行消息仍作为普通文字处理。当前适配范围为上表，并未包含全部 CLI 或 Desktop 专用命令；宿主不支持的接口会明确报错。压缩、审查和分叉的修改操作已完成模拟后端浏览器验收；本轮原生实机核验覆盖技能、模式和 MCP 的只读查询，没有对真实聊天执行会消耗模型额度的审查或压缩。

## 模型、权限与状态

- 模型来自原生 `model/list`，推理档位使用各模型的 `supportedReasoningEfforts`，并非所有模型都具有相同档位。
- 自定义供应商在 Codex 中配置，Remote 没有独立供应商编辑器；可选模型由运行时暴露的目录决定。
- 模型和项目元数据在已认证的初始化请求中加载，重连时刷新，不会在连接保持期间持续刷新。目前这两类列表只读取首次请求页；任务列表、历史和权限配置具有各自的分页处理。
- 新会话当前使用模型目录的默认推理档位初始化，可能与 Codex 全局配置覆盖值不同，请显式选择需要的强度。
- 权限来自 `permissionProfile/list`，修改作用于当前会话。内置配置包括 `:read-only`、`:workspace`、`:danger-full-access`。
- 主聊天的未发送草稿保存在浏览器 `sessionStorage`，切换任务和重连时保留，不与桌面输入框或其他设备同步；临时侧聊草稿仅存在于内存。
- 图片通过本地 Codex 工作流处理，项目不提供独立托管的模型服务。

## 设备通知

打开 **设置 → 消息通知**，可以开启网站通知、发送测试通知、关闭此设备通知。iPhone、iPad 需要 iOS / iPadOS 16.4 或更新版本：通过 Safari 打开 HTTPS 网站，添加到主屏幕，从该图标进入后点击开启并授予系统权限。其他浏览器需要支持 Web Push。普通局域网 HTTP 地址不支持此功能；localhost 是浏览器的开发例外。

通知由 Remote 服务端推送，页面关闭后也可接收；Remote 与原生 Desktop 连接需要保持运行。通知范围是在 Remote 打开或新建过的普通会话，包括完成、失败、停止的回合、新出现的原生待答问题及需要确认的请求；重复的单条／整回合事件不会重发同一个问题，从历史加载的旧问题也不会推送，不包含子智能体和临时侧聊。点按通知会返回工作区并打开对应会话。

送达不依赖页面的 WebSocket 或 HTTP 事件流。后台通知遇到临时网络错误、HTTP 429 或服务端错误时，会在 1 秒、4 秒后各重试一次，保留同一通知标签；过期订阅会移除，取消订阅后停止后续尝试。

VAPID 密钥、设备订阅及通知会话范围保存在私有运行数据 `data/web-push.json` 中，更新时需要保留，不可提交 Git。加密消息由 Apple 或浏览器厂商等推送服务传递；通知包含会话标题、状态、会话标识和最多 100 个字符的最终回复或问题摘要。标题可能回退到原生会话预览，这些内容可能出现在设备锁屏上。不包含工具和命令输出；标题读取超过 1.5 秒时使用默认标题继续推送。关闭通知只影响当前设备；成功退出登录也会移除本设备订阅。浏览器登录过期本身不会撤销系统推送订阅，可使用关闭按钮或取消该网站的通知权限。送达取决于系统通知设置、专注模式及推送服务；服务端发送成功不代表已经在真实手机上显示。

## 加载与手机网络

项目和模型缺失时分别通过鉴权 HTTP 读取，不再等待实时连接握手，也不互相等待。目录及会话初始正文、计时读取遇到临时错误时最多尝试三次，间隔为 0.5 秒、1 秒；正文与计时每次尝试均允许 15 秒，覆盖完整响应体下载。切换会话会取消读取与退避；登录过期和永久客户端错误不重试。补播重连会补齐未完成读取，保留已经成功加载的会话。

已有主会话的订阅重加入最多尝试三次，会话或连接变化后停止；不会重发提示词或模型操作。

普通焦点变化、页面显示事件不会改写握手期限，重复 online 不会销毁健康连接。真实后台挂起会暂停未完成握手，返回时按当前阶段重新计时。普通焦点变化也不会取消健康的任务列表读取；超过两秒的首屏请求仅在真实离线恢复或后台返回时替换。

- 切换会话、跳转历史窗口或关闭会话时，会取消过期的 HTTP 历史下载；相同的进行中读取共用一个请求。历史及权限 HTTP 读取超过 15 秒会超时；任务读取采用下述期限和自动恢复。读取任务或打开聊天遇到登录过期时，会返回登录页。权限读取跟随所选目录。取消读取不会停止模型回合，也不会撤销已经发给原生后端的操作。
- 任务读取失败后，无论实时连接是否就绪，都会在 0.5、1、2、4 秒、最多 5 秒后自动重试。首次尝试以 4 秒为限，后续 HTTP 尝试允许 15 秒；仅在真实离线恢复或后台返回时，替换已挂起至少 2 秒的任务首屏读取。普通焦点和重复 online 事件保留进行中的读取。共享的原生快照及模型、项目读取以 8 秒为限，避免重试继续加入已卡住的原生请求。
- 主聊天的 WebSocket 等待连接最多 3 秒、等待同步最多 6 秒；连接 500 毫秒后仍未建立，就并行预热受鉴权的 HTTP 事件流，采用先连上的通道并关闭另一候选。失败时也会改用 HTTP 事件流和 POST，保留相同的原生操作、会话订阅与事件补播。成功的 HTTP 路线在当前标签页会话中记住，但不提供登录权限；HTTP 连接和同步分别以 12 秒为限。单条 POST 失败只影响对应请求，保留健康事件流；登录过期或连接标识失效仍会关闭通道。读取与心跳不再排队等待模型操作的确认。只有同步、订阅和心跳等安全控制会重试；模型操作和审批响应只发送一次，丢失确认也不会自动重发。
- 心跳回包允许 12 秒，以容纳移动网络往返。页面隐藏时暂停探测，返回前台或恢复页面时重新探测，避免把后台挂起的计时器误判为断线。心跳成功不会掩盖同步未完成。前台断线重试从 250 毫秒开始，间隔最多 5 秒；重连按钮替换连接及旧的任务、历史下载，保留工作区与草稿，不重复登录检查。源站完全不可达时仍无法同步；交互式 PTY 终端继续使用独立的 WebSocket。
- 初始化 HTTP 与 WebSocket 共用进行中的模型／项目查询；已完成结果只复用五秒，覆盖两次连接间的传输时间。创建项目和桌面桥接断开会清除相关结果。会话内容和模型操作不使用此元数据缓存。

- 登录状态检查与受登录保护的初始化请求同时启动，任一服务端校验成功即可进入工作区，状态检查卡住时不会阻塞已成功的初始化。两项读取均有 6 秒超时；全部失败后按 1、2、4 秒、最高 8 秒间隔重试。网络恢复或重新切回页面时，可取消未完成校验并重新开始。密码登录成功后直接进入，不再额外等待一次登录检查。
- HTTP 初始化数据返回后立即显示任务、模型和项目，不等待 WebSocket。通过服务端鉴权、启用任务加载后，若初始化超过 1.5 秒仍未完成，会通过独立的受保护 HTTP 接口读取任务；缺失的模型和项目也通过各自的鉴权 HTTP 读取，不依赖实时同步。其余任务页沿原生游标逐步读取，并让出输入和选择操作的时间，全部任务仍可访问。实时连接建立期间也能加载聊天历史，发送消息和原生操作仍需实时连接就绪。
- 任务首批最多 50 条，其余沿原生游标按每页最多 200 条自动补齐。初始化与独立任务接口复用原生读取，包括超过初始化等待时限的请求。选中聊天时，后续任务分页先暂停，优先读取正文。
- 打开聊天时先读取原生元数据和最近 40 项记录，不等待恢复会话或计时元数据。如果密集执行记录中缺少可见的用户提问与最终回复，会自动沿原生游标再补最多两页、每页 100 项，保留最新记录与剩余游标。首次读取最多 240 项；更远历史仍随上滑加载。计时独立加载；发送与队列操作等待原生数据、计时和恢复会话确认。更早历史和缺失的计时页通过鉴权 HTTP 读取，不再依赖实时 RPC；首次计时读取失败也不会关闭上滑加载，上滑可以自行取得初始计时游标。
- 主机内存保留任务首屏与最近五个聊天，最长五分钟，新鲜期两秒；原生事件使快照失效，暂态显示后通过共享请求刷新。受保护接口仍使用 `no-store`，快照不能授权操作。
- 服务端鉴权成功后，固定设备可先显示 IndexedDB 快照，再后台刷新。最多保存 1000 条任务摘要、最近三个聊天各 40 项，总计不超过 1 MiB，保留 24 小时。只保存正文和轻量已完成活动，不保存图片内容、推理、工具输出、文件 diff、权限、临时侧聊或子智能体聊天；不会恢复运行状态或分页游标。退出登录、检测到登录过期或清理站点数据会清除快照。这属于设备私有存储，与公开的 Service Worker 缓存分开。
- 向上阅读时，会提前将一页历史及其原生计时信息预取到内存，更早记录自动加载，无需点击加载按钮。服务器遇到没有可读对话的记录时，会在一次响应内合并最多四个原生页，每页 100 项，保留全部记录和原生游标，减少手机逐页往返。首次插入需同时满足距顶部不超过 64px、手指已松开、滚动已停止 160ms。随后沿用这次上滑意图，在保持阅读位置的同时继续，直到用户消息或最终回复真正显示在执行折叠区外；下载到旧回复但仍被折叠进当前回复时，不会误判为已经展示历史。向下滑动、跳转或展开执行过程会停止连续补页。请求返回时若正在进行新手势，会继续等待；若已向下离开顶部，则保留预取结果，等再次上滑时使用。插入时保持可见消息的位置和执行过程的展开状态。子智能体查看标签使用同样的机制。预取失败不打断阅读；正式读取失败后再次上滑即可重试，静止时不会循环请求。完整历史页不持久保存，只有上述有容量限制的设备快照会存入本地。
- 普通 HTTP 响应和支持压缩的 WebSocket 消息启用压缩；HTTP 事件流不压缩并立即刷出，使用 `no-store, no-transform` 避免缓冲。带版本文件名的资源使用长期不可变缓存；已认证的初始化和历史响应使用 `no-store`。
- 原生事件更新对应任务；回合完成只刷新最新目录页。全列表和历史校准最多每五分钟一次。后台分页在隐藏标签页暂停，弱网下让出交互时间。流式更新按 60ms 合并，弱网为 100ms，隐藏页面为 250ms。Markdown 复用已完成块，未变化的回复保留原有组件。会话块采用真实布局高度，图片缩略图预留稳定区域并完整显示图片，查看器仍可打开原图。
- 短暂 WebSocket 中断从主机内存补发已订阅事件，日志上限为 90 秒、2 MiB。后台任务列表尚未翻页完成时，已经完整读取的聊天也会保持原状。游标过期或主机重启时恢复原生快照。补发事件去重，审批重新读取待处理快照；中断的模型请求不会自动重发。
- 生产环境的 Service Worker 仅缓存公开应用外壳和静态资源。再次打开时立即返回已安装外壳，页面与模块保持同一版本，新版本在后台安装；关闭所有 Remote 窗口后重新打开，可启用等待中的更新。首次打开会预加载工作区模块。不缓存 API、聊天、审批、图片或终端数据，离线外壳不代表可离线读取会话。支持的 HTTPS 浏览器可安装应用；Safari 可使用“添加到主屏幕”。
- 成功登录后仅保存一个布尔型设备标记：再次进入时先显示空白工作区，后台验证登录。标记不含凭据或聊天数据，不代表访问权限；任务和 WebSocket 仍等待服务端确认。登录过期或退出时清除标记。这缩短的是整页等待，不代表网络鉴权往返已变快。
- 浏览器本地 User Timing 标记 `remote:shell`、`remote:auth`、`remote:bootstrap`、`remote:tasks`、`remote:chat`、`remote:connected` 分别记录各阶段最近一次完成时间，不含消息内容，也不会自动上传。受控优化前后对照及真机验收限制见[启动验收记录](startup-acceptance.md)。
- 固定可信设备可在日常使用的浏览器或已安装应用中登录一次，再将入口固定到主屏幕或任务栏。HTTP-only 会话默认有效 30 天（`SESSION_DAYS`）；过期、退出登录、清理站点数据或重置服务端会话密钥后需要重新登录。保持使用同一 HTTPS 域名和浏览器配置；主屏幕应用可能使用独立的浏览器存储。
- 隧道安装脚本默认 HTTP/2。Windows 的 `scripts/install-task-windows.ps1` 接受 `-TunnelProtocol auto|http2|quic`；macOS 隧道安装脚本接受 `TUNNEL_PROTOCOL`。切换前应在实际主机比较，动态请求仍可能受网络路由影响。

手机历史加载会保留 Safari 到顶回弹前的上滑意图，并累计连续的小幅手指移动。主动向下滑仍会停止连续加载；新记录会等待手指离开且滚动停稳后再插入。

### 更新主屏幕应用

1. 联网打开 Remote，让新版 Service Worker 在后台安装。
2. 关闭所有 Remote 窗口，包括主屏幕应用和同域名浏览器标签页，再重新打开。
3. 让新版成功验证一次登录。以后在同一浏览器或应用存储中打开，即可使用设备标记快速进入。

设备标记不能替新设备登录，也不能让过期会话继续有效。首次进入或浏览器存储不可用时仍需等待服务端验证。主界面提前出现时，任务数据可能仍在加载。清理站点数据会移除安装缓存与标记，也可能需要重新登录。应用外壳、已认证任务、可读聊天和实时发送连接具有不同的就绪时间；受控浏览器测试尚不能代表真实 iPhone 5G／Wi-Fi 延迟。

侧边栏“设置”旁显示当前页面的版本号，菜单关闭时也能看到，无需等待连接。

### 可选边缘静态托管

使用 Cloudflare Workers Static Assets 提供公开前端文件，已认证的 `/api/*`、`/ws`、`/health` 继续走现有 Tunnel。安装并登录 `cf` CLI，为已有部署设置域名和区域：

```powershell
$env:REMOTE_EDGE_HOST = "codex.example.com"
$env:REMOTE_EDGE_ZONE = "example.com"
npm run deploy:edge
```

macOS 使用 `REMOTE_EDGE_HOST=codex.example.com REMOTE_EDGE_ZONE=example.com npm run deploy:edge`。
仅挂载应用外壳的明确路径及 `/assets/*`，不会发布主机数据或修改 DNS。传输协议变化时先部署匹配后端。修改前端后需重新部署边缘资源，仅重启本地服务不会更新它。

### 可选局域网备用入口

在实际安装目录执行 `npm run setup:lan`，再重启 Remote。默认开启 4546 端口的第二个监听，与原服务共享认证、会话和终端。设置菜单显示公网及可用的局域网/VPN 地址。命令可附加端口参数，`LAN_ADDRESS` 可指定优先显示的本机 IPv4 地址。

备用入口使用可信局域网/VPN 内的 HTTP，不应作为公网入口。PWA 安装、听写等 HTTPS 功能仍使用公网 HTTPS 地址。Windows 防火墙设置需要管理员权限；命令提示无法添加规则时，在管理员终端重新执行。设备和路由器也须允许互访。将 `LAN_PORT=0` 并重启可关闭它。

执行 `node scripts/benchmark-network.mjs https://codex.example.com 10` 可复用连接测量首页与动态健康请求的中位耗时、P95 和失败数。主机测量不能替代真实手机、移动网络或已登录 macOS 桌面端的验收。

若 Tunnel 日志中的边缘地址落入代理的 `198.18.*` Fake-IP 范围，而非真实 Cloudflare 地址，需要在黑名单模式的 `dns.fake-ip-filter` 现有列表中追加 `+.argotunnel.com`。Clash Verge 应修改持久化 DNS 设置，不能只改运行时生成的 YAML，否则刷新配置后会丢失。保留其他过滤项，热加载内核并清除 Fake-IP 缓存，通过代理实际 DNS 监听器确认 `region1.v2.argotunnel.com`、`region2.v2.argotunnel.com` 返回真实地址；若隧道连接仍不可用，再重启 Tunnel。进程运行但就绪连接为零时，公网依然不可用。仅改用 HTTP/2 无法修复错误的 DNS 应答。

关闭 DNS 覆写后，如果实际系统／代理解析已经返回真实地址，也可以直接保持关闭。需以当前生效的解析器为准：订阅本身仍可能启用 Fake-IP，不能仅凭开关状态判断。

如果本机直连 TCP `7844` 可用，可以在 TUN 代理的持久化 `tun.route-exclude-address` 列表中追加 Tunnel 的 IPv4 边缘网段 `198.41.192.0/24`、`198.41.200.0/24`，配合 `+.argotunnel.com` 返回真实 DNS 地址，保留其他过滤项和排除项。这样切换 TUN 时，隧道连接仍走物理网络，不影响其他代理流量。采用前应检查 Windows 实际路由、隧道就绪状态和连接数量；某些网络仍需通过代理。不要固定单个边缘 IP 或会变化的 Wi-Fi 地址。Clash Verge 应将排除项保存在全局配置脚本与持久化 DNS 设置中，并在刷新配置后验证。

Windows `Status` 除了查看计划任务，还会检查后端健康、Desktop 桥接、隧道就绪状态和边缘连接数量。进程显示 `Running` 不代表公网可用。切换页面可能产生请求取消日志；边缘拨号超时、就绪连接为零属于另一类故障。计划任务的崩溃重启不能修复不可用的网络出口。

从 0.1.1 起，Windows 隧道任务通过轻量 Node 看护运行。已有安装在构建后重新执行 `npm run install-task:windows` 即可更新任务。cloudflared 退出后 1 秒拉起，连续崩溃时退避到最多 5 秒。看护每 2 秒检查本地边缘连接，并监听 Windows 网络地址和可用性变化；未产生系统事件的代理切换由轮询覆盖。只要仍有可用边缘连接就保留进程。全部连接持续不可用 4 秒、且经过启动后的 8 秒宽限后，确认 TCP 7844 出口可达，再次检查连接仍未恢复才重建隧道。重建保留 15 秒冷却，网络变化时重新检查。关闭远控会禁用任务并结束其所属子进程，直到手动开启才恢复。看护不会修改代理设置或重启 Desktop、网页后端，日志保存在私有 `data/tunnel-supervisor.log`。出口检查使用 Cloudflare 两个边缘区域域名；只允许 UDP 的网络可能仍依赖 cloudflared 自身恢复。此看护由 Windows 控制脚本安装；macOS 的独立隧道服务仍单独管理。

网页前台心跳改为每 5 秒一次，仍允许慢速手机回复等待 12 秒。主会话心跳 2 秒未回复时，并行验证一个新的鉴权 HTTP 通道；新通道确认有响应后才接管，旧通道先回复则取消候选。接管后正常同步并补齐事件，保留界面、草稿和已加载记录，状态不确定的模型操作不会重发。页面隐藏时暂停探测，重新进入前台时立即检查。

## 已知限制

- 当前界面标签为简体中文，项目提供中英文文档。
- 项目是独立适配，不是所有 Codex Desktop 界面的像素级复制。
- 桌面内部协议变化可能影响同步；独立回退模式不能复现桌面实时事件。
- Remote 终端不接管 Desktop 已有的 shell。检查器依赖已加载会话中的文件与变更，并非完整项目文件管理器。
- 命令审批已完成实机验证。文件修改、用户输入、持久命令和网络策略审批有辅助逻辑与测试，但仍需分别完成实机验收。
- 听写依赖浏览器支持和麦克风权限，本次发布尚未验收真实语音输入。
- 心跳重连不能保证网络永不掉线，结果不确定的模型操作不会自动重放；部分只读请求有次数限制的重试。
- 真实 iPhone Safari／添加到主屏幕应用，以及 5G／Wi-Fi 长尾延迟仍需真机测试。Chromium 和 Windows WebKit 模拟不能证明 iOS 性能。
- Windows 已完成在线实测。macOS 已纳入构建、单元测试、shell 与 LaunchAgent CI；桌面实时同步、登录自启和旧隧道方案仍需在已登录的 Mac 上验收。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 桌面会话没有实时更新 | 检查 `/health` 是否为 `desktop`，确认调试页面存在且桌面端已登录 |
| 聊天记录看起来不完整 | 加载更早历史，检查是否连接到桌面端所属后端 |
| 缺少某个模型或推理档位 | 查看 Codex 提供的目录，修改供应商后重新连接 |
| 开启时提示缺少构建 | 先运行 `npm ci` 和 `npm run build` |
| 本机正常但公网打不开 | 检查隧道就绪状态、计划任务、DNS 和 `data/cloudflared.log` |
| 休眠后连接停滞 | 回到前台或恢复网络，客户端会检测并重连 |
| 再次打开仍显示完整登录检查 | 启用等待中的 PWA 更新，并在同一浏览器或应用中成功验证一次；过期会话或存储不可用时仍需验证 |
| 主界面很快打开，任务或聊天仍慢 | 外壳和已认证数据分别就绪；查看本地 `remote:auth`、`remote:tasks`、`remote:chat` 标记，并比较实际网络路径 |
| 忘记访问密码 | 在主机运行 `npm run set-password` |
| Codex 提示忽略某个全局设置 | 检查本机 Codex 配置，Remote 不负责管理废弃全局配置项 |

提交问题时，请提供操作系统、Node 版本、相关 Codex 版本、传输方式和脱敏错误。不要附带令牌、`.env`、认证文件、原始聊天导出或未脱敏截图。

## 开发

```bash
npm ci
npm run dev
```

前端由 Vite 提供，开发配置将 API 和 WebSocket 转发到本地后端。生产实例运行时，不要再启动一个争用同一桌面桥接的后端。

```bash
npm run typecheck
npm test
npm run build
```

测试覆盖历史、连接恢复、原生提问、摘要、更新、预览、通知及真实 PTY；数量以对应提交的 CI 为准。CI 在 Windows、macOS 和 Ubuntu 上运行类型检查、测试和生产构建。macOS 任务还检查 shell 语法，并用系统原生 plist 工具验证生成的 LaunchAgent。这些检查不能替代已登录桌面端的实机测试；Ubuntu 构建不代表 Linux 桌面集成已经验证。

```text
src/client/       React 工作区、输入框、历史、审批与重连
src/server/       Express、认证、桌面桥接与原生历史
src/shared/       协议与权限辅助逻辑
scripts/          安装、自启、隧道与平台开关
public/           应用资源
docs/images/      脱敏文档截图
```
