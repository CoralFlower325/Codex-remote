# Remote 0.2.34 发布与部署验收

日期：2026-11-10。组件：Remote **0.2.34** / manager **0.2.9**。

## 巨型轮次与历史补页修复

- 历史窗口的整轮回退增加跨度上限。单轮在窗口内占用超过 200 条时改按条锚点
  切口，保留完整 800 条窗口，避免穿越巨型轮次头部时一次卸下正在阅读的整段
  内容；普通轮次仍整轮保留。
- 已完成轮次的最终答案计时锚点一旦被观察到，会在本次查看内记忆。答案滑出
  窗口后继续使用该锚点，不再在最终答案时刻与原生总时长之间翻动；进行中轮次
  不写入记忆。
- 向下补页在距离条件之外增加向末端移动或近期明确向下手势的要求，避免极短
  窗口顶部持续命中补页范围，导致历史页在边界上反复乒乓。
